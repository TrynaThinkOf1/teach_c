# Well, how do you create a program that you can run to try out what you've learned?

### There are a few options.
- You could use VSCode in a new project and edit a file to write your C code, it may even do syntax
highlighting if you use a `.c` file extension.
- What might work is a combination of the TextEdit utility on MacOS and a terminal (to run your code, discussed in next file).
- My personal beginner favorite is the Nano terminal text editor and then you can compile and run the
programs right there in your terminal anyway.

To use Nano, simply go into your terminal and whatever directory you want, such as `learning/`, and
type
```bash
nano my_file.c     # or whatever file name you'd like instead
```

Nano will drop you in a brand new empty file in which you can type whatever you want, using the keys
that make the most sense: enter for new line, tab for indentation, and arrow keys to move around.
You can safely ignore all of the special macros at the bottom of the page. Once you're done writing,
you can type `^X` (control+x) and then it will prompt whether you want to save the file, just type `y`.

If you want to go back and make changes to this file, simply type `nano` and the file name and it will
drop you at the top of that file ready to make changes, navigate using the arrow keys.
